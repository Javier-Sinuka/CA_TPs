## Contrato comprobado

`riscv_defs.vh` define los códigos; no se cambiaron. El RTL asigna
`o_result=0` antes del `case`, cubre las diez ramas y devuelve 0 por
defecto. Es lógica combinacional sin clock ni almacenamiento.

| Código | Operación | Interpretación y resultado |
|---:|---|---|
| 0 | ADD | suma módulo 2^32 |
| 1 | SUB | resta módulo 2^32 |
| 2 | SLL | desplazamiento lógico izquierdo por `b[4:0]` |
| 3 | SRL | desplazamiento lógico derecho por `b[4:0]` |
| 4 | SRA | desplazamiento aritmético derecho, `a` signed, por `b[4:0]` |
| 5 | AND | bit a bit, unsigned |
| 6 | OR | bit a bit, unsigned |
| 7 | XOR | bit a bit, unsigned |
| 8 | SLT | comparación signed; palabra 0 o 1 |
| 9 | SLTU | comparación unsigned; palabra 0 o 1 |

El TB conserva vectores constantes conocidos y añade un oráculo separado
de 64 bits: extiende signo de modo explícito, aplica máscara de 32 bits
a la aritmética y reduce el desplazamiento a cinco bits. El producto de
bordes cubre 0, 1, −1, `0x7fffffff` y `0x80000000` contra las diez
operaciones. Los shifts prueban 0, 1, 31, 32, 63 y cantidades con bits
altos. Hay 1000 pares pseudoaleatorios, cada uno aplicado a las diez
operaciones, y códigos 10..15 más X/Z para verificar el default.
