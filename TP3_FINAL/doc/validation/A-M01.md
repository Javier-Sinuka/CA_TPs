## Resultado reproducido

Herramientas locales: Python 3.12.3, Icarus Verilog 12.0 (stable),
Verilator disponible con `--lint-only -Wall`. Desde `Practico/TPs`:

```bash
python3 TP3_FINAL/tools/run.py tbs
```

En una copia temporal creada desde el HEAD, sin `TP3_FINAL/build/`,
y con el `run.py` de A-06, el comando terminó con exit 0:

| TB | Resultado |
|---|---:|
| `tb_alu` | PASS, 10.396 chequeos |
| `tb_alu_control` | PASS, 133.149 chequeos; 781 patrones válidos |
| `tb_imm_gen` | PASS, 70 chequeos |
| `tb_control` | PASS, 102 chequeos |

Total: **143.717 chequeos**. Los cuatro módulos elaboraron y pasaron
`verilator --lint-only -Wall` sin warnings. Los cuatro TB compilaron
con `iverilog -g2012 -Wall -Wno-timescale` sin warnings. Cada TB exige
exit 0, línea `PASS <top>:` y ninguna línea `FAIL`.

La matriz de [32 instrucciones más HALT](../documentation/matriz_isa.md)
y las evidencias [A-01](A-01.md), [A-02](A-02.md), [A-03](A-03.md),
[A-04](A-04.md), [A-05](A-05.md) documentan cobertura y brechas.
`ALU_*` se define una sola vez en `riscv_defs.vh`: ADD=0, SUB=1,
SLL=2, SRL=3, SRA=4, AND=5, OR=6, XOR=7, SLT=8, SLTU=9.
El dump v1 recibido usa esos cuatro bits en `info_ex[21:18]`;
en MEM/WB ese campo debe salir cero por ausencia de transporte.
