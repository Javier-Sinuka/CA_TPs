# TP1 - ALU

Implementacion parametrizable de una ALU combinacional para FPGA.

## Estructura

```text
src/          Fuentes sintetizables: ALU y modulo superior.
sim/          Testbench y otros archivos exclusivos de simulacion.
constraints/  Restricciones de pines de la placa FPGA (.xdc).
doc/          Documentacion para el informe.
```

Los directorios y productos generados por Vivado no se versionan. Para abrir
el proyecto local existente, las fuentes de `src/` y `sim/` deben agregarse o
actualizarse desde Vivado.
